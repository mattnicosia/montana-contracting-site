# Montana Contracting

Static portfolio website for [Montana Contracting](https://montanacontracting.com).

## Local development

```sh
npm start
```

The site is available at `http://localhost:4173`. Run `npm test` to verify page metadata, inline JavaScript, project slugs, internal routes, and referenced assets.

## Deployment

The repository is configured for Vercel. `vercel.json` enables the clean `/pre-construction` route for `pre-construction.html`.
